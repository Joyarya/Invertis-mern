WEEK 8: Dashboard with CSS Grid
Track: CSS Grid
Concepts: display: grid, fr unit, gap, grid-template-areas, repeat + auto-fit + minmax, flex inside grid

--------------------------------------------------------------------------------
OBJECTIVE:
--------------------------------------------------------------------------------
Build two-dimensional layouts using CSS Grid.

--------------------------------------------------------------------------------
PROBLEM STATEMENT (FINAL QUESTION / PROJECT GOAL):
--------------------------------------------------------------------------------
Make a dashboard page with a top bar, a side menu, a main area and a footer.
Fill the main area with small boxes that arrange themselves automatically.

--------------------------------------------------------------------------------
TASKS (COVERS 8.1 TO 8.5):
--------------------------------------------------------------------------------
8.1 Make a grid with display: grid, columns, the fr unit and gap.
8.2 Make the boxes with repeat(auto-fit, minmax(150px, 1fr)) so they re-arrange by themselves.
8.3 Name the areas: head, side, main, foot using grid-template-areas.
8.4 Inside each box use Flexbox to put the icon and text side by side.
8.5 Check your grid in DevTools (Grid inspector) and submit.
